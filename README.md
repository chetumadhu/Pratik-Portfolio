## 🚀 Overview

This portfolio was developed as part of the **Agentic AI: AI-Assisted Personal Portfolio Website** assignment. It highlights the collaborative workflow between human design direction and AI-assisted engineering tools (Claude Code / Agentic AI).

### 🛠️ Core Deliverables

1. **Personal Portfolio Website**
   - **Hero Section**: Portfon Framer-inspired arch dome, custom typography, floating badges with micro-interactions, and true alpha mist fade.
   - **About & Philosophy**: Human-centered design principles across FinTech, B2B SaaS, and Enterprise UX.
   - **Bento Grid**: Interactive cards displaying satisfaction scores, project highlights, and service pedestals.
   - **Responsive Design**: Fluid mobile, tablet, and ultra-wide layouts.

2. **Selected Case Studies**
   - **[ScoreUp (AI FinTech)](case-studies/scoreup.html)**: Simplifying Credit Intelligence with AI-Powered Insights & Personalisation.
   - **[ICICI Express Home Loans](case-studies/icici-home-loans.html)**: Revamping Banking UX for a faster, intuitive customer experience.
   - **[DecorBvibes](case-studies/decorbvibes.html)**: Premium architectural branding & visual identity design system.
   - **[BlinkX Trading Platform](case-studies/blinkx.html)**: Revolutionizing retail investment and single-swipe trading flows.

3. **AI-Assisted Development Workflow**
   - **Design Direction**: Human-led layout planning, visual hierarchy, and interaction goals.
   - **Prompt Engineering**: Iterative prompt refinements to resolve complex visual edge cases (alpha transparency vs. white fog, parallel tag slants, CSS keyframe physics).
   - **GenAI Element**: Studio lighting portrait with background composite and custom mathematical alpha feathering.
